## 📊 STEP 3: MONITOR YOUR ADS (Daily)

### **First 24 Hours - Watch Closely**

**Check These Metrics:**
```
Reach: How many people saw your ad
Impressions: How many times shown
Cost Per Result: How much per purchase
Link Clicks: People clicking to your site
CTR (Click-Through Rate): Should be 1%+
CPC (Cost Per Click): Should be ₹10-30
Purchases: Actual sales (goal!)
ROAS (Return on Ad Spend): Should be 1.5x+
```

**Access Performance:**
1. Go to: https://adsmanager.facebook.com/
2. Select your campaign
3. View metrics in the table

---

### **What to Look For:**

**✅ GOOD SIGNS:**
```
CTR: 1.5%+ (people are clicking)
CPC: ₹10-20 (affordable clicks)
Purchases: 1+ per day (conversions happening)
ROAS: 1.5x+ (profitable)
```

**⚠️ WARNING SIGNS:**
```
CTR: < 0.5% (ad not resonating)
CPC: > ₹40 (too expensive)
Purchases: 0 after 3 days (not converting)
ROAS: < 0.8x (losing money)
```

```
Action: PAUSE & ANALYZE
1. Check Pixel tracking (is Purchase event firing?)
2. Check landing page (is it loading fast?)
3. Review ad creative (is it relevant?)
4. Review audience (too broad? too narrow?)
```

## ⚠️ COMMON MISTAKES TO AVOID

### **1. Changing Too Early**
```
❌ Don't change anything in first 3 days
❌ Don't panic if no sales on Day 1
❌ Don't increase budget > 50% at once
✅ Wait for learning phase to complete
```

### **2. Wrong Audience**
```
❌ Too broad: "All India, All ages"
❌ Too narrow: "Bangalore only, 50-52 years"
✅ Sweet spot: "All India, 45-65 years"
```

### **3. Bad Creative**
```
❌ Generic stock photos
❌ No clear CTA
❌ Boring copy
✅ Emotional hook + social proof + clear action
```

### **4. Ignoring Data**
```
❌ Running ads without checking metrics
❌ Not reading Facebook recommendations
❌ Ignoring high CPC or low CTR
✅ Check dashboard daily, optimize weekly
```

## 🔧 TROUBLESHOOTING

### **Problem: High CPC (> ₹40)**
```
Causes:
- Audience too small
- Ad not relevant
- Low quality score

Solutions:
1. Broaden audience (add more interests)
2. Improve ad copy (more compelling)
3. Test different image
4. Check website load time
```

### **Problem: No Purchases**
```
Causes:
- Pixel not tracking
- Landing page issues
- Price too high
- Audience mismatch

Solutions:
1. Test Pixel with Pixel Helper
2. Check page load speed (< 10s)
3. Test checkout flow yourself
4. Review audience targeting
5. Test lower commitment CTA (free assessment)
```

### **Problem: High Frequency (> 3)**
```
Cause: Showing ads to same people too many times

Solution:
1. Expand audience
2. Create more ad creatives
3. Reduce budget temporarily
4. Add audience exclusions
```

# 📱 Meta Pixel Setup Guide - Dharmic Parents

## 🎯 What is Meta Pixel?
Meta Pixel (formerly Facebook Pixel) tracks user actions on your website for Facebook/Instagram advertising. Essential for:
- **Retargeting visitors** who didn't convert
- **Creating lookalike audiences** based on your customers
- **Tracking conversions** from Facebook/Instagram ads
- **Optimizing ad delivery** to people likely to take action

## 🔑 How to Get Your Meta Pixel ID

### Step 1: Access Events Manager
1. Go to [Facebook Events Manager](https://business.facebook.com/events_manager2)
2. Select your business account (or create one)

### Step 2: Create or Find Your Pixel
- **If you have a pixel already:**
  - Click on your pixel name
  - Copy the **Pixel ID** (15-digit number like `123456789012345`)

- **If you need to create a new pixel:**
  1. Click **"Connect Data Sources"** → **"Web"**
  2. Choose **"Meta Pixel"**
  3. Enter your website name: `Dharmic Parents`
  4. Enter your website URL: `https://dharmicparents.com`
  5. Click **"Create Pixel"**
  6. Copy the **Pixel ID** that appears

### Step 3: Pixel Implementation Options
We'll use **Manual Code Installation** (most reliable):
- Don't use the "Partner Integration" options
- Choose "Install code manually" 
- We'll handle the technical implementation

## 🎯 Standard Events We'll Track
For your dharmic parenting business, we'll set up these key events:
- **PageView** - Every page visit
- **ViewContent** - Assessment/content pages
- **Lead** - Assessment completions, email signups
- **InitiateCheckout** - Checkout page visits
- **Purchase** - Successful transformations guide purchases
- **CompleteRegistration** - Survey completions

## 🚀 Custom Events for Your Business
- **StartAssessment** - When users begin father-son assessment
- **CompleteAssessment** - Assessment completion with score
- **HighValueLead** - High relationship health scores (potential customers)
- **BookmarkContent** - Users who spend significant time on page
